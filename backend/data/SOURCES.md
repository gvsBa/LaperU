# Sumber katalog referensi lokal

Tanggal pemeriksaan publik: **29 Oktober 2026**. Sumber utama adalah direktori resmi Canteen Facility Telkom University. Ini **bukan verifikasi lapangan atau jaminan real-time**. Artikel bertanggal 2024/2026 dapat tertinggal dari kondisi usaha saat ini. Tidak ada klaim harga, jam, status buka, koordinat atau kepemilikan telah dikonfirmasi hari ini. Tanggal artikel adalah tanggal pada indeks situs bila tersedia, bukan tanggal verifikasi operasi.

Data minimum yang digunakan: nama, area/alamat yang disebut sumber, kategori ringkas, ringkasan menu tanpa klaim kualitas, URL sumber. Tidak menyalin foto, ulasan orang, nomor kontak pribadi, atau peringkat sumber menjadi ulasan mahasiswa. Aplikasi menyimpan snapshot JSON lokal sehingga tidak perlu mengambil data dari internet saat demo.

## Pemisahan simulasi

12 usaha dengan akhiran `(Simulasi)` dan semua akun mahasiswa/pemilik `showcase.laperu.local` adalah fiktif. Menu/harga, 180 ulasan, 108 balasan, 216 favorit, dan 360 tayangan dibuat untuk pengujian, bukan statistik penggunaan nyata. Referensi usaha nyata tidak diberi ulasan/rating/favorit/tayangan sintetis oleh seed ini.

`listing_sources.data_kind` membedakan `PUBLIC_REFERENCE` dari `SIMULATION`. `checked_on` adalah tanggal pemeriksaan sumber publik. Tidak ada status "terverifikasi pemilik" untuk referensi; nilai approval database seed hanya menampilkan katalog dalam API demo. Pengelola internal referensi berstatus SUSPENDED sehingga tidak bisa login sebagai pemilik usaha nyata.
